# Incident AI — Person 2

This feature owns provisional classification, severity, extracted details, processing, uncertainty, and failure presentation. No AI UI or client-side inference is implemented in the foundation.

Add components, query hooks, and tests when this feature begins. Export reusable UI from a public `index.ts` then. Coordinate shared models in `src/services/contracts/`, and provide matching mocks and future API adapters. Results must be described as estimates, not verified facts; absent data is unknown, not low severity.
